## `@nebula-lab/hooks`

Reusable React hooks — state, DOM observation, and lifecycle utilities every other package builds on.

| SN | Component | Props | Usage notes | Comments |
|---|---|---|---|---|
| 1 | `useBoolean` | `initialValue: unknown` — The initial boolean value.<br>**returns** `[boolean, UseBooleanActions]` — A `[value, actions]` pair — `actions` has a stable identity, safe to destructure and pass to child components without causing re-renders. | Boolean state with named setters instead of a raw `setState` — reads better at call sites (`open.setTrue()` vs `setOpen(true)`) and the actions object has a stable identity across renders. |  |
| 2 | `useClickOutside` | `refs: RefObject<HTMLElement> \| RefObject<HTMLElement>[]` — One ref, or an array of refs — an outside click must miss all of them to fire `handler` (e.g. a popover's trigger button *and* its content).<br>`handler: (event: PointerEvent) => void` — Called with the triggering `PointerEvent`.<br>`enabled?: boolean` — Set `false` to detach the listener without unmounting.<br>**returns** `void` | Calls `handler` when a pointer-down event occurs outside every element in `refs` — the basis for dismissing popovers/menus/dialogs on outside click. |  |
| 3 | `useControllableState` | `prop?: T` — The controlled value. | 4 | `useDebounce` | `value: T` — The value to debounce.<br>`delay: unknown` — Milliseconds of stability required before the debounced value updates.<br>**returns** `T` — The debounced value. | Returns a debounced copy of `value` that only updates after `delay`ms have passed without `value` changing. |  |
| 5 | `useEventListener` | `eventName: K` — Any key of `WindowEventMap`, e.g. `'resize'`, `'keydown'`.<br>`handler: (event: WindowEventMap[K]) => void` — Called with the typed event.<br>`target?: RefObject<EventTargetLike> \| EventTargetLike \| null` — A ref, element, `window`/`document`, or `null`/omitted (defaults to `window`).<br>`options?: boolean \| AddEventListenerOptions` — Standard `addEventListener` options/boolean.<br>**returns** `void` | Attaches `handler` for `eventName` on `target` (defaults to `window`) and cleans it up automatically. |  |
| 6 | `useFocusTrap` | `ref: RefObject<T>` — The container whose focusable descendants should be trapped.<br>`active: unknown` — Whether the trap is currently engaged.<br>**returns** `void` | Traps Tab/Shift+Tab focus cycling within `ref`'s subtree while `active` is true, and restores focus to whatever was focused beforehand on cleanup — the keyboard-behavior half of the WAI-ARIA Dialog (Modal) pattern. |  |
| 7 | `useId` | `prefix?: string` — Prepended to the generated id, e.g. `'nebula-tabs'`.<br>**returns** `string` — A unique, SSR-safe id string. | Wraps React's built-in `useId` with an optional, human-readable prefix (`useId('nebula-tooltip')` -> `"nebula-tooltip-:r0:"`) — handy for debugging generated `id`/`aria-*` wiring in devtools without losing React's SSR-safe hydration-matched id generation. |  |
| 8 | `useIntersectionObserver` | `ref: RefObject<T>` — The element to observe.<br>`options?: IntersectionObserverInit` — Standard `IntersectionObserverInit` (`root`, `rootMargin`, `threshold`).<br>**returns** `IntersectionObserverEntry \| undefined` — The latest `IntersectionObserverEntry`, or `undefined` before the first observation. | Observes `ref` via `IntersectionObserver` and returns the latest `IntersectionObserverEntry` (`undefined` until the first observation fires). |  |
| 9 | `useLocalStorage` | `key: string` — The `localStorage` key.<br>`initialValue: T \| (() => T)` — The value (or a lazy initializer) used when nothing's stored yet.<br>**returns** `[T, Dispatch<SetStateAction<T>>]` — A `[value, setValue]` pair, same shape as `useState`. | `useState` backed by `localStorage`, synced across tabs/windows via the `storage` event. |  |
| 10 | `useMediaQuery` | `query: string` — Any valid media query, e.g. `'(min-width: 768px)'` or `'(prefers-color-scheme: dark)'`.<br>**returns** `boolean` — Whether `query` currently matches. | Tracks whether `query` (a CSS media query string, e.g. `'(min-width: 768px)'`) currently matches. |  |
| 11 | `useMounted` | **returns** `() => boolean` — A stable function returning `true` while the component is mounted. | Returns a ref-backed `() => boolean` you can call after an async operation resolves to check the component is still mounted before calling `setState` — avoids the classic "state update on an unmounted component" warning without needing a cleanup flag re-declared in every effect. |  |
| 12 | `useMutationObserver` | `ref: RefObject<T>` — The element to observe.<br>`callback: (mutations: MutationRecord[], observer: MutationObserver) => void` — Called with each `MutationRecord[]` batch and the observer instance itself (handy for calling `observer.disconnect()` from inside the callback).<br>`options: MutationObserverInit` — Standard `MutationObserverInit` — at least one of `attributes`/`childList`/`characterData` (with `subtree` if needed) must be `true` or the browser throws.<br>**returns** `void` | Observes DOM mutations (attribute/child-list/subtree changes) on `ref`'s node via `MutationObserver` and calls `callback` with each batch of records — for reacting to DOM changes an app doesn't control directly (a third-party widget injecting nodes, a contenteditable region, watching for a class/attribute another… |  |
| 13 | `usePrevious` | `value: T` — The current value.<br>**returns** `T \| undefined` — `value` as of the previous render, or `undefined` on the first render. | Returns the value `value` held during the previous render (`undefined` on the first render). |  |
| 14 | `useResizeObserver` | `ref: RefObject<T>` — The element to observe.<br>**returns** `Partial<Size>` — `{ width, height }` (content-box, in CSS pixels) — both keys absent until the first observation fires. | Observes `ref`'s content-box size via `ResizeObserver` and returns the latest `{ width, height }` (both `undefined` until the first observation fires). |  |
| 15 | `useScrollLock` | `locked: unknown` — Whether scrolling should currently be locked.<br>**returns** `void` | Locks `document.body` scrolling while `locked` is true — used by modal/dialog/drawer overlays. |  |
| 16 | `useStableCallback` | `callback: (...args: Args) => R` — The (possibly frequently-changing) callback to stabilize.<br>**returns** `(...args: Args) => R` — A stable function that always invokes the latest `callback`. | Returns a function with a stable identity across renders that always calls the latest `callback` — lets you omit a frequently-changing callback from a `useEffect`/`useMemo` dependency array without going stale or re-running the effect every render. |  |
| 17 | `useSwipe` | `options: UseSwipeOptions`<br>**returns** `UseSwipeResult` | Pointer-based drag/swipe gesture tracking — reports a live delta while dragging and resolves to directional callbacks on release, with no opinion about what a "swipe" should *do* (advance a slide index, dismiss a card, etc). |  |
| 18 | `useToggle` | `values: readonly [T, T]` — The `[first, second]` pair to toggle between.<br>**returns** `[T, () => void, (value: T) => void]` — A `[value, toggle, setValue]` tuple — `toggle` flips between the two values; `setValue` jumps to a specific one. | Generic toggle state over any two-value set, not just booleans — e.g. `useToggle(['list', 'grid'])` for a view switcher. |  |
| 19 | `useVirtualizer` | `options: UseVirtualizerOptions`<br>**returns** `Virtualizer` | List virtualization — computes which of `count` items actually fall (plus `overscan`) inside the scroll element's visible window, so a consumer only renders those instead of the full list. |  |
